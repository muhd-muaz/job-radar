# Inbox: paste job ads here

For ads from JobStreet, LinkedIn or anywhere else that can't be collected automatically.

1. On GitHub, open this folder and click **Add file > Create new file**.
2. Name it like `2026-10-23-company-role.txt`.
3. Paste the ad. Optional header lines at the top help:

```
Title: Data Analyst
Company: Example Sdn Bhd
Location: Kuala Lumpur
URL: https://...
```

The next daily run scores it with the rest. Delete the file when you're done with the job.
